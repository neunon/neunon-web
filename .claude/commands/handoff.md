description: 作業を中断してもう片方のエージェントへ引き継ぐ（commit → push → 作業ログ更新）
---

利用上限が近い、または作業を区切るので、**もう片方のエージェント（Codex / Claude Code）が
続きを拾える状態**にしてから終わる。以下を順にやること。

1. `git status` で未コミットの変更を確認する
2. 途中でもよいので commit する。メッセージには**どこまでやったか**を書く
3. 作業ブランチを `git push -u origin <ブランチ名>` で push する
   （`main` への直接 push はしない。本番デプロイが走る）
4. `docs/AGENT_LOG.md` の 1〜5 を**今の状態に書き直す**（追記ではなく上書き）
   - 「1. いま進行中のこと」— 何を、どのファイルで、どこまで
   - 「2. 次にやること」— 次に入った側が迷わない粒度で
   - 詰まった点があれば「5. ハマったこと」に書く
   - 最終更新日と更新者（Claude Code）を直す
5. AGENT_LOG.md も commit して push する

最後に、**引き継ぎ先にそのまま貼れる短い文**を出力する。
ブランチ名・今の状態・次の一手を含めること。
