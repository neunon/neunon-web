## 3. 決まったこと（勝手に覆さない）

- 本番は Render Static Site。`origin/main` への push で自動デプロイされる
- 既存 URL の構造は変えない。末尾スラッシュ統一を維持する
- 新規 LP・記事の量産、分析ツール導入は今回のスコープ外
- 人材パネルは Microsoft Lists 連携。「サイト掲載可」の運用を守る
- プライバシーポリシー／利用規約はリーガルチェック待ち。中身を書き換えない
- **事業詳細ページは「専用コンポーネント + content JSON」方式**（2026-09-25 決定）。
  汎用テンプレートに分岐を足さず、事業ごとにコンポーネントを分ける。
  文言修正が JSON だけで完結する状態を保つこと
- **デザインの基準はパッケージ型支援ページ**（発注者指示）。全幅セクションを明暗交互に、
  各セクションは英字ラベル＋見出し＋補足のヘッダーで始める
- **見出しは資料の言い方をそのまま使う。言い換えて調子をつけない**（発注者指示）。
  「意思決定のテーマから、支援を組み立てる。」のような言い回しはAIらしいと指摘され、
  「主な支援テーマ」に戻した経緯がある
- **横スクロールさせない**（発注者指示）。図は幅に収める。収まらない図は、
  文字が12pxを割る幅で隠し、テキストの代替（経路表記など）に委ねる
- **コントラスト比4.5:1以上**。デジタル庁デザインシステムの基準に合わせる

## 6. ハマったこと・共有事項

- `markitdown` はこの環境に無い。pptx の読み取りは `python-pptx`。
  出力は `PYTHONIOENCODING=utf-8` か `encoding="utf-8"` を必ず指定（既定の cp932 で落ちる）
- **スライドの図形はz順で返る。ラベルと本文の対応は `shape.top`/`shape.left` で
  並べ直してから確定させること。** 抽出順のままだと対応がずれる。
  価格図の数値は埋め込みチャートから取れる（`shape.chart.series`）
- Claude Code のプレビュー機能（launch.json）は、セッション途中でフォルダを切り替えると
  旧フォルダを見に行く。`npm run dev` を自分で起動する方が確実
- **この環境ではスクリーンショットが撮れない**（ペインが描画されない）。
  レイアウト検証は DOM の実測（getBBox・getBoundingClientRect・getComputedStyle）で行った
- `MotionLayer` は `.nc-doc-body > section` 等に `nc-reveal` を付けて opacity:0 から出す。
  一方 `app/globals.css` のコメントは「要件定義書9.2がスクロール連動フェードを禁止」と
  書いており、実装と食い違っている。今回の新ページは reveal 対象に当たらないので無影響だが、
  既存ページの扱いは未整理
- リモートブランチ `origin/codex/publish-readiness` と `origin/seo-metadata` は
  すでに `main` へ取り込み済みの残骸。参照しない
- ローカルの `main` は古いことがある。作業前に必ず `git fetch origin` する
