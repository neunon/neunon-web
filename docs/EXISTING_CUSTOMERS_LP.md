## SEOと検索意図

主対象は「既存顧客の企業分析・調査を外部に依頼したい」「深耕営業のための個社別資料が欲しい」という発注検討。主軸は **既存顧客 企業分析／企業調査 代行**、副次は **既存顧客 深耕／取引先 企業調査／クロスセル 提案仮説**。検索ボリューム・CPC・難易度の実測値は未取得。数値による優先順位付けは行っていない。

検索結果では「既存顧客 深耕」は方法論の記事が中心で、直接の発注検討より情報収集が強い。一方「企業調査 代行」には調査サービスが現れるが、アンケート調査や市場調査も混在する。このLPは対象を「既存顧客の個社調査」と明示し、**何を調べるか→どう分析するか→どんな資料が届くか→営業で何を確かめるか**を具体化する。一般的な深耕営業の手法は今後の記事テーマに分ける。

親の[パッケージ型支援](https://neun-on.com/services/package/)は複数の調査メニューを俯瞰し、このLPは既存顧客の企業分析に限定する。Title・H1・見出しもその棲み分けで設定。将来の記事候補は「既存顧客の企業分析で確認すべき項目」「担当交代時の顧客理解の引き継ぎ」「営業の提案仮説を立てるための公開情報の読み方」。記事は今回追加していない。

## デザインとコンテンツ判断

- サイト共通のヘッダー・フッターと既存ボタンを維持。本文だけをスコープ付きCSSで作り、他ページを変えない。
- ダークなファーストビューに、白い個社別レポートを重ねて「形のある成果物」を主役にした。紫は既存サイトと親和性のある限定的なアクセント。
- 白・淡色・ダークの切り替えと、行形式・工程レール・資料・FAQの異なる構造で、カードの単調な反復を避けた。
- レポート4ページは実在企業の情報を使わない架空サンプル。事業構成比50/30/20は合計100%。提案仮説は事実と区別している。
- 価格、納期、顧客名、受注成果、実績数は未確認のため創作しない。「1社から相談」と範囲に応じた見積りだけを記載。
- 指示に挙がった `事業拡大構想(1).docx`、`企業クローズアップ_提案書(1).pptx`、`提案書用材料_クローズアップ系.pptx`、`添付ファイルについて.txt` は、このワークスペース内には見つからなかった。内容の最終照合には原本の確認が必要。

## 実装箇所

- ページ・構造化データ・メタ情報: `app/services/package/existing-customers/page.tsx`
- コピー: `content/service-pages/existing-customers.json`
- 資料プレビュー・拡大操作: 同ルートの `ReportVisual.tsx` と `ReportGallery.tsx`
- 専用スタイル: 同ルートの `page.module.css`
- 親ページからの内部リンク: `components/services/PackageServiceDetail.tsx`
- XMLサイトマップ: `app/sitemap.ts`

`Service` と `BreadcrumbList` のJSON-LDを追加。全体の`Organization`は共通レイアウトに既存実装があるため重複追加していない。FAQリッチリザルトは前提とせずFAQ構造化データは置いていない。canonical、OG、Xカードは共通の `createPageMetadata` を利用。OG画像は現時点で共通画像を利用しており、固有画像の制作は公開前の改善項目。

CTAは既存の `/contact/` に接続し、サンプルボタンはページ内の実物プレビューへ移動する。資料ダウンロードや新規フォームは作成していない。各CTAの配置は `data-cta-location` で識別可能だが、リポジトリにはGA4/GTMタグが見当たらないため送信イベントは追加していない。`generate_lead` は問い合わせ完了時だけに割り当てるべきで、クリック時には送らない。
