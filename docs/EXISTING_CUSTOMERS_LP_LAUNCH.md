# 既存顧客企業クローズアップ LP：公開・計測・広告テスト

最終更新: 2026-10-28

## 公開

- 正式 URL: `https://neun-on.com/services/package/existing-customers/`
- パッケージ型支援ページからのリンク、canonical、構造化データ、サイトマップを同じ URL にそろえる。
- 旧デザイン確認 URL `/design-review/existing-customers-claude/` は削除する。
- 公開後、実機相当のスマートフォン幅でファーストビュー、成果物拡大、料金、フォームへの遷移を確認する。
- Search Console は `https://neun-on.com/` のプロパティと `/sitemap.xml` が登録済み（2026-10-28 確認）。公開後に正式 URL を「URL 検査」し、必要ならインデックス登録をリクエストする。

## 問い合わせ計測

- LP の問い合わせリンクに `source=existing_customers` を付ける。氏名、メールアドレス、相談内容は計測イベントに入れない。
- フォーム API の成功応答後だけ一時マーカーを保存し、完了ページで `contact_submit_success` を `dataLayer` に一度だけ積む。`source` は `existing_customers` または `other`。
- 主コンバージョンはフォームの正常受付。CTA クリック、サンプル閲覧、フォーム到達は補助指標。単なる完了ページ表示を主コンバージョンにはしない。
- 現在、外部解析タグは読み込まない。GA4 の測定 ID と Google 広告のコンバージョン ID が発行され、プライバシー文書・同意設計の確認が完了してから有効にする。`app/privacy/page.tsx` は法務確認前に変更しない。
- GA4 導入後は `contact_submit_success` を `generate_lead` に対応づけ、Google 広告では同じ受付を一つの主コンバージョンとして扱う。重複計測、テスト送信、個人情報の送信がないことを検証する。

## Google 広告の初回検証案

- Google 広告の初期アカウント枠は作成済み。キャンペーン、請求情報の登録や配信開始は未実施。LP URL の入力前で停止中（画像取得・利用権の確認と規約への同意が伴うため）。
- まず検索広告 1 キャンペーン、LP 1 URL に限定する。初回は日本語、東京・関東を対象にする。関東は東京都・神奈川県・埼玉県・千葉県・茨城県・栃木県・群馬県を想定。
- 地域オプションは「対象地域にいる、または定期的にいるユーザー」を選ぶ。地域に関心があるだけのユーザーを初回テストに含めない。
- 月額上限の意向は税込 40,000 円として安全側に扱う。平均日予算を 1,150 円とすると、通常の月間広告費用上限は `1,150 × 30.4 = 34,960 円`。日本の消費税 10% を加えた目安は 38,456 円。実際の請求・適用条件を広告管理画面で確認し、**キャンペーンは 1 本のみ**で開始する。日ごとの費用は平均日予算を上回ることがある。
- 広告文は LP の実際の内容だけを使う。「既存顧客企業を分析」「次の提案に向けた調査」「企業ごとの分析レポート」などを候補にし、実績や納期を創作しない。
- 初期キーワード候補は「既存顧客 分析」「顧客企業 分析」「企業調査 レポート」「営業 提案 企業分析」。マッチタイプと除外語は検索語句を確認して調整する。初回からディスプレイ広告や自動拡張を広げない。
- 運用開始後は少なくとも週 1 回、検索語句、費用、LP 到達、正常受付件数を確認。問い合わせの質を確認してから拡張する。

### 検索広告の原稿案（未入稿）

最終 URL: `https://neun-on.com/services/package/existing-customers/`。見出しは30文字、説明文は90文字以内（日本語の全角文字は2文字換算）で作成。広告の審査結果と実際の表示は入稿後に確認する。

見出し候補:

- 既存顧客の企業分析
- 顧客企業を1社ずつ調査
- 次の営業提案につなげる
- 企業調査を1社から
- 取引先の事業を深く知る
- 分析レポートで納品
- 1社3,000円から
- Neunon Consulting

説明文候補:

- 既存顧客の業績・事業・商品・動向を調査し、提案の切り口まで整理します。
- 1社から依頼できる企業分析。スライド形式のレポートで納品します。
- 取引先ごとの提案余地を見極めるため、公開情報と任意の取引情報を照合します。

初期の除外語候補: `求人`、`転職`、`採用`、`学生`、`無料テンプレート`。検索語句レポートで確認してから追加・修正する。
