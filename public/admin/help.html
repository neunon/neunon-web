EDITOR GUIDE

管理サイトの使い方

公開文言と画像を編集し、内容を確認してから公開するためのガイドです。編集にはご自身の GitHub アカウントでログインしてください。公開サイトの反映には少し時間がかかります。

公開までの流れ

  1. 編集する場所を選ぶ

    トップ、採用、企業情報、事業、お知らせ、LP、SEO設定などから選択します。問い合わせ履歴は右下の別画面で確認します。

  2. 保存して確認する

    文章と画像を入力し、見出し・リンク先・誤字・スマートフォンでの読みやすさを確認します。非公開の項目は公開前に表示設定を確認してください。

  3. 公開申請・承認する

    管理画面の編集ワークフローで公開に進みます。GitHub の変更提案とサイトの自動ビルドが通ってから本番へ反映されます。反映後は実ページを開いて確認します。

どこで何を変更するか

トップページ

ヒーロー、次世代の力、事業紹介・管理体制・学生向け・お知らせの見出しと説明、表示・非表示、末尾の相談案内。

事業・採用・企業情報

各事業の説明、メニュー、FAQ、価格関連文言、採用の募集要項・人物像・選考フロー、会社概要と共通ナビの表示文言。

ニュース・LP・追加セクション

記事や LP の新規作成・非公開・削除ができます。「既存ページにセクションを追加」では、各ページに文章、カード、画像＋文章、FAQ、CTA を追加・並べ替えできます。公開済みのURL用IDは変えないでください。

SEO設定

主要ページのタイトル・検索説明・SNS共有画像を編集できます。検索結果の表示文面は Google 側で変わることがあります。

SEO と広告用ページの注意

1ページに1つの主題を決め、内容に合う見出しと具体的な説明を付けてください。画像には内容を伝える代替テキストを入力します。SNS画像は横1200×縦630pxを推奨します。変更後は表示・リンク・モバイル表示を確認してください。

Google 広告を始める際は、広告ごとに LP を作り、広告文と LP の内容を一致させます。URL には計測用 UTM を付けられます。ただし広告タグ・コンバージョン計測は、広告アカウント、計測対象、プライバシー同意の運用を決めてから実装します。現時点では管理画面からタグを直接挿入できません。

編集できない項目

フォームの項目・送信先の仕組み、ログイン権限、法務文書、特殊な図やアニメーションの構造は、安全性と整合性のためコード管理です。変更したい場合は管理者に依頼してください。会社情報のメール表示を変えても、フォームの実際の配送先は変わりません。
